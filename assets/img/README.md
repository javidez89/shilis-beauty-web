# Procedencia de las imágenes

Los siguientes recursos son recortes extraídos de la pieza `374869.jpg` aportada como referencia por el cliente:

- `logo-original.webp`: marca gráfica original, rasterizada.
- `afiche-original.webp`: pieza publicitaria completa (sin interfaz de red social).
- `portada-referencia.webp`: modelo de la pieza publicitaria.
- `cepillado.webp`, `manicure.webp`, `pedicure.webp`, `queratina.webp`, `cejas.webp`: ejemplos visuales extraídos del afiche.

Ninguno de estos recortes constituye autorización independiente para uso comercial ajeno a la marca. No afirmar que sean fotos de trabajos reales del salón. Sustituir por fotografías propias autorizadas cuando estén disponibles.

`favicon.svg` fue desarrollado para la maqueta como un monograma conceptual, no como logotipo oficial alternativo.
